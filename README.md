# ИИ от сбора до внедрения: кликер-бот на YOLOv8

Проект автоматизации кликер-игры с использованием YOLOv8 для детекции объектов (реклама, бонусы, улучшения, игровое поле).

## Структура проекта

```
cookie_ai/
├── app.py              # Основной бот: детекция + клики
├── train.py            # Обучение YOLOv8
├── screener.py         # Сбор датасета (скриншоты)
├── autolabel.py        # Авторазметка по эталонам
├── split_dataset.py    # Разбивка train/val (80/20)
├── data.yaml           # Конфиг датасета для YOLO
├── class.txt           # Список классов
├── requirements.txt    # Зависимости
├── yolov8n.pt          # Базовая модель YOLOv8n (pre-trained)
```

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Сбор данных: играйте, чтобы попасть реклама, бонусы, улучшения
python screener.py                                  # кадры -> screenshorts/

# 3. Создание эталонов (2-4 на класс)
python crop_template.py screenshorts/<файл>.png ad_close
python crop_template.py screenshorts/<файл>.png upgrade
python crop_template.py screenshorts/<файл>.png bonus
python crop_template.py screenshorts/<файл>.png game

# 4. Автоматическая разметка
python autolabel.py --preview preview
#    --thr 0.8     если эталоны находятся плохо (по умолчанию 0.85)
#    --merge       дополнить рамки в уже размеченных кадрах
#    --model best.pt   дополнительно разметить обученной моделью

# 5. Проверка и правка в X-AnyLabeling (папка screenshorts)

# 6. Разбивка датасета и обучение
python split_dataset.py --clean
python train.py

# 7. Запуск бота (при необходимости поправьте путь к best.pt в app.py)
python app.py
```

## Классы объектов

| Класс | Описание |
|-------|----------|
| `game` | Игровое поле (печенька) |
| `ad_close` | Кнопка закрытия рекламы (крестик) |
| `upgrade` | Доступные улучшения (не серые) |
| `bonus` | Бонусы (золотые печеньки и др.) |

## Правила разметки

- **upgrade** — только доступные улучшения (не серые), иначе бот кликает по недоступным
- **ad_close** — рамка вокруг крестика/кнопки закрытия, а не всей рекламы
- Минимум **30–50 примеров** на класс
- Если кнопки плохо детектятся — в `train.py` увеличьте `imgsz` до 960 (при 640 мелкие кнопки теряются)
- Папка обучения называется `cookie_detecror` (как в `train.py`). Если существует — YOLO создаст `cookie_detecror2` и т.д.: поправьте путь в `app.py`

## Как это работает

- **Авторазметка** (`autolabel.py`): поиск эталона через `cv2.matchTemplate` на нескольких масштабах, NMS для удаления дублей, экспорт в формат YOLO (класс, x_центр, y_центр, ширина, высота — в долях от кадра)
- **Бот** (`app.py`): скриншот → инференс → сортировка по классам → действия по приоритету: реклама → бонусы → улучшения (не чаще 1 раза/сек) → 10 кликов по печеньке
- **Безопасность**: мышь в угол экрана — аварийная остановка (`FAILSAFE`), либо Ctrl+C. На macOS терминалу нужны разрешения «Запись экрана» и «Универсальный доступ»

## Итеративное улучшение

После первого обучения:
1. Новые кадры размечаются моделью: `--model best.pt --merge`
2. Проверяются в preview/
3. Дообучаются: `python train.py`
